# Установочный пакет setup для Windows (NSIS)

Установщик `calculator-1.0-setup.exe` собирается скриптом **NSIS** (`calculator.nsi`).

## Состав

| Файл | Назначение |
|------|------------|
| `calculator.nsi` | Скрипт установщика: копирует приложение в `C:\Program Files\Calculator`, создаёт лаунчер, ярлыки («Пуск» + рабочий стол), деинсталлятор, запись в «Установку и удаление программ» |
| `app/calculator/` | Исходный код приложения, который упаковывается в установщик |

## Требование на целевой системе

**Python 3 с модулем Tkinter** (при установке с python.org галочка «tcl/tk and IDLE» включена по умолчанию).
Инсталлятор проверяет `python` в PATH и предупреждает, если он не найден.

## Сборка установщика

Из этой папки (`packaging/win-setup`):

```bash
# Linux + wine, портативный NSIS:
wine /путь/к/nsis-3.10/bin/makensis.exe calculator.nsi

# Или на самой Windows с установленным NSIS:
makensis calculator.nsi
```

Результат: `calculator-1.0-setup.exe` (в git не коммитится, см. `.gitignore`).

## Установка и удаление на Windows

1. Запустить `calculator-1.0-setup.exe` от имени пользователя (запросит права администратора).
2. После установки — ярлык «Calculator» на рабочем столе или в меню «Пуск».
3. Удаление: «Параметры → Приложения → Calculator → Удалить» или запустить `C:\Program Files\Calculator\uninstall.exe`.

## Примечание

`app/calculator/` — это копия исходников проекта (без venv и `__pycache__`).
При изменении кода приложения её нужно обновить перед пересборкой установщика.
